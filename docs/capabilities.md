# Capability registry

Generated from `core/capabilities.mjs`; API and the secondary product dialog use the same source. Run `node scripts/check-capabilities.mjs --write` after changing it. Tests reject drift or supported claims with missing witnesses.

SUPPORTED means the named local behavior has automated test witnesses. It does not certify live Cloudflare, every Git workflow, production security or global semantic correctness.

- **SUPPORTED:** Implemented bounded local behavior with automated witnesses.
- **PARTIAL:** Implemented subset with explicit remaining boundaries.
- **EXPERIMENTAL:** Implemented path with limited deployment evidence.
- **UNSUPPORTED:** No delivered operational workflow; planned where applicable.
